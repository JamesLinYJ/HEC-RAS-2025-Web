# Flood Studio materials

Bundled 1K PBR textures from [Poly Haven](https://polyhaven.com), licensed [CC0](https://polyhaven.com/license).
These files are served locally; the application does not call the Poly Haven API at runtime.

- [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02): diffuse, OpenGL normal, and packed ambient occlusion / roughness / metalness maps.
- [Concrete Floor Worn 001](https://polyhaven.com/a/concrete_floor_worn_001): diffuse, OpenGL normal, and packed ambient occlusion / roughness / metalness maps.

Original JPG maps are unmodified. Albedo uses sRGB; normal and packed maps use linear data. Terrain normals and surface shading add material detail without displacing the solver geometry.
